# Devion — Liquid Glass Portfolio

A responsive, no-build static website redesign for GitHub Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — liquid-glass theme, responsive layout and animations
- `script.js` — scroll reveal, mobile menu, theme toggle and animated particles
- `certificate.pdf` — keep your existing certificate PDF here

## Publish on GitHub Pages
1. Download and extract the ZIP.
2. In your existing `Devion` GitHub repository, upload/replace `index.html`, `styles.css`, and `script.js`.
3. Keep the existing `certificate.pdf` in the repository root so the certificate buttons continue to work.
4. Commit the changes. GitHub Pages will update the site automatically.

The existing portfolio text and paragraphs have been retained in the redesigned HTML. External font loading is optional; system fallbacks are included. The background uses lightweight CSS gradients and a small canvas particle field. Reduced-motion preferences are respected.
